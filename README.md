# 🎒 سایت کلاس ما

سایتِ ساده و **کامل** برای کلاس برنامه‌نویسی — استادِ تکالیف، اطلاعیه‌ها و برنامه‌ی کلاس را می‌گذارد و همه می‌بینند.

## ✨ امکانات

- **ورود دوگانه:**
  - 🧑‍🎓 **دانش‌آموز** — رمز: `1111` → دیدن تکالیف، اطلاعیه‌ها و برنامه‌ی کلاس
  - 🧑‍🏫 **استاد** — رمز: `89463` → افزودن / ویرایش / حذفِ تکالیف، اطلاعیه‌ها و جلسه‌ها
- **مشترک و واقعی:** استاد با اتصال به گیت‌هاب، داده‌ها را در فایل `data.json` داخل همین ریپو ذخیره می‌کند و همه همان را می‌بینند.
- **برنامه‌ی کلاس:** یکشنبه‌ها ۱۸:۰۰ تا ۱۹:۳۰ (آنلاین) و سه‌شنبه‌ها ۱۰:۳۰ تا ۱۲:۰۰ (حضوری).
- تاریخ تحویل با «چند روز مانده» و «مهلت گذشته» به‌صورت فارسی.
- رابط فارسی، راست‌به‌چپ و واکنش‌گرا (روی موبایل هم خوب است).
- حالت دمو: تا وقتی گیت‌هاب وصل نشده، داده‌ها روی همان مرورگر ذخیره می‌شوند.
- 🔒 **رمز استاد در صفحه‌ی ورود نمایش داده نمی‌شود.**

## 📁 فایل‌های پروژه

| فایل | نقش |
|------|------|
| `index.html` | کل سایت (تک‌فایل، شامل CSS و JS) |

## 🚀 راه‌اندازی (تک‌بار انجام شد)

این ریپو روی **گیت‌هاب پیجز** فعال است (شاخه‌ی `main`، پوشه‌ی `/`). کافی است فایل‌ها را در آن آپلود/به‌روز کنید.

برای بارگذاری با git:
```bash
git init
git add .
git commit -m "سایت کلاس"
git branch -M main
git remote add origin https://github.com/Pillow1243/kelas_site.git
git push -u origin main
```

### اتصالِ ذخیره‌ی مشترک (توسط استاد)
1. در گیت‌هاب: **Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token** را بزنید.
2. فقط تیکِ **`repo`** را بزنید و توکن را کپی کنید (به شکل `ghp_...`).
3. در سایت با رمز استاد (`89463`) وارد شوید.
4. در بخش «اتصال به گیت‌هاب»: نام کاربری `Pillow1243`، ریپو `kelas_site`، شاخه `main`، مسیر `data.json` و توکن را بگذارید.
5. **ذخیره‌ی اتصال** را بزنید. حالا هر تغییری برای همه ذخیره می‌شود. ✅

> 🔒 **نکته‌ی امنیتی:** توکن فقط در مرورگرِ خودِ استاد ذخیره می‌شود و هرگز به دانش‌آموزان داده نمی‌شود.
