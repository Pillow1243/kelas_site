# 🎒 سایت کلاس ما

سایتِ ساده برای کلاس برنامه‌نویسی — **استاد اطلاعاتش را روی گیت‌هاب می‌گذارد، همه می‌بینند.** بدون هیچ توکن و API.

## 🔑 ورود
- 🧑‍🎓 **دانش‌آموز:** رمز `1111` → دیدن تکالیف، اطلاعیه‌ها و برنامه‌ی کلاس
- 🧑‍🏫 **استاد:** رمز `89463` → همراه با راهنمای افزودن اطلاعات

https://pillow1243.github.io/kelas_site/

## 📌 چطور استاد اطلاعات را اضافه کند؟ (خیلی ساده)

سایت هیچ دیتابیسی ندارد؛ فقط فایل **`data.json`** را می‌خواند و نشان می‌دهد. پس:

1. به فایل `data.json` در ریپو برو:  
   https://github.com/Pillow1243/kelas_site/blob/main/data.json
2. دکمه‌ی ✏️ (ویرایش) را بزن.
3. یک آیتم موجود را کپی کن، یا در ابتدای لیست یک آیتم جدید بگذار.
4. روی **Commit / ذخیره** بزن. چند ثانیه بعد همه می‌بینند.

### قالبِ هر آیتم (کپی کن، پر کن):
```json
// برای تکلیف:
{ "title": "عنوان", "course": "درس", "due": "2026-09-20", "link": "https://...", "desc": "توضیح" }

// برای اطلاعیه:
{ "title": "عنوان", "content": "متن", "date": "2026-09-08" }

// برای جلسه:
{ "day": "یکشنبه", "start": "18:00", "end": "19:30", "note": "آنلاین" }
```
> ⚠️ یادت باشد بعد از آخرین آیتمِ هر لیست، **ویرگول** (`,`) را فراموش نکنی. اگر فایل خراب شود، سایت چیزی نشان نمی‌دهد — پس موقع ویرایش دقت کن.

## 📁 فایل‌ها
| فایل | نقش |
|------|------|
| `index.html` | کل سایت |
| `data.json` | داده‌های تکالیف، اطلاعیه‌ها و برنامه |
| `.nojekyll` | برای سرو درست فایل‌ها |

## 🔑 تغییر رمزها
در `index.html`، ابتدای `<script>`:
```js
const CONFIG = { studentPass: "1111", teacherPass: "89463" };
```

## 🧪 اجرای محلی
```bash
python3 -m http.server 8080
# آدرس: http://localhost:8080
```
